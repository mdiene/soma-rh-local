**Type** : open source (HRMS sur ERPNext). **Source** : [documentation officielle](https://docs.frappe.io/hr/introduction).

**Modules documentés** : organisation (départements, grades, organigramme) ; présence (check-in, pointage automatique, appareils biométriques) ; shifts (types, plannings, demandes) ; congés (politiques, allocations, encaissement, calendrier des jours fériés) ; performance (cycles, objectifs, feedback) ; voyages et notes de frais ; recrutement (offres, candidats, entretiens, offres d'emploi, cooptation) ; formation ; cycle de vie (intégration, mutations, entretien de sortie, départ) ; paie et fiscalité (structures salariales, tranches d'impôt, déclarations) ; avantages (gratuité, prêts, heures supplémentaires, rappels) ; application mobile.

**À retenir pour SOMA-RH** : structure de la doc par module + cas d'usage ; shifts et rosters ; notes de frais ; recrutement ; départ et solde ; check-in mobile. **Limite** : fiscalité à localiser (pas de règles Sénégal natives).
