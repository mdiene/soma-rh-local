**Source** : [hayot-expertise.fr](https://hayot-expertise.fr/blog/lucca-vs-payfit-vs-silae-paie-sirh-pme-2026). Tarifs indicatifs, à confirmer.

| | PayFit | Lucca | Silae |
|---|---|---|---|
| Positionnement | paie autonome TPE/PME, interface simple | SIRH modulaire sans moteur de paie | production de paie des cabinets |
| Paie | oui, DSN intégrée | non (fournit des variables) | oui, 900+ conventions |
| Modules | Paie, Paie avancée, HR+ | congés, temps, notes de frais, entretiens | production, contrôles avant transmission |
| Intégrations | Pennylane, Sage, Cegid | API ouverte, connecteurs compta | FEC, Cegid, MyUnisoft |
| Cible | 5 à 150 salariés | 50 à 500 | PME/ETI multi-conventions |

**À retenir** : onboarding guidé, contrôles avant transmission, connecteurs comptables natifs, API ouverte. Les obligations françaises (DSN, conventions) ne s'appliquent pas au Sénégal.
